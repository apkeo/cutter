# Cutter 1.3

Marketing-ready cursor motion, editable clicks, and the complete precision editing improvements from 1.2.

- Fixed the macOS Apple Silicon corner-render regression by keeping composition overlays in RGB.
- Added **Hide system cursor** to the capture picker. Cursor positions and arrow/text/hand states are recorded in every video capture mode.
- Added separate cursor and click timeline layers with eye toggles, event times, editable positions, shapes, buttons and hold durations.
- Added Font Awesome Free cursor and mouse icons with button highlights and expanding click rings.
- Added **Smooth** cursor motion with cubic interpolation, jitter reduction and exact click anchors.
- Preview and export use the same cursor animation. Native cursor data and edits are saved in a `.cutter.json` sidecar next to the original video.
- Aligned cursor rows with the video timeline and synchronized export frame clocks for accurate button-release timing.
- Included the 12× crop magnifier, edge snapping, proportional corner radii, timeline fixes and continuous monitor dragging from 1.2.

## Downloads

Windows: `.exe` installer or portable `.zip`. macOS: `arm64` for Apple Silicon, `x64` for Intel; `.dmg` or `.zip`.

macOS requires Screen Recording and Input Monitoring permission. Builds remain unsigned: Windows may show SmartScreen, and macOS may require Privacy & Security → Open Anyway.

Keep the source video and its `.cutter.json` together to preserve editable cursor data. Original cursors baked into video cannot be removed afterward; hide the system cursor before recording for a clean replacement. Custom cursor shapes may fall back to an arrow and can be edited.

This release is published only after native Windows, macOS Intel and macOS Apple Silicon builds and packaged-app export tests pass. SHA256SUMS.txt contains checksums.
