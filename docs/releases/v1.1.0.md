# Cutter 1.1

One capture picker. Move freely between displays. Keep only the sound you want.

- Fixed duplicate capture pickers on multi-monitor desktops: only one picker opens, on the last used display (or the display under your pointer).
- Drag the selected area across a display edge to move the picker to that monitor. The selected display and region are remembered.
- Added **Mute audio** for imported videos, applied to both playback and exported MP4, MOV and WebM files. Your preference is saved between sessions.
- Clips without an audio track show a clear indication. Screen capture currently records video only.

## Downloads

Windows: choose the `.exe` installer or portable `.zip`.
macOS: choose `arm64` for Apple Silicon or `x64` for Intel, then download the `.dmg` or `.zip`.

These builds are unsigned. Windows may show SmartScreen; choose More info → Run anyway after verifying the source. On macOS, use System Settings → Privacy & Security → Open Anyway if prompted. Allow Screen Recording permission for capture.

Native builds and packaged import/export tests run on all three platforms before publication. SHA256SUMS.txt contains download checksums.
