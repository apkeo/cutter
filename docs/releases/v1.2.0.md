# Cutter 1.2

Pixel-perfect crops, individual corners and a smoother timeline.

- **12× pixel magnifier:** a floating crop preview with a pixel grid, exact coordinates and the crop boundary.
- **Edge snapping:** nearby horizontal and vertical edges are detected in the current image or paused video frame. Guides show the alignment. Hold Alt to bypass snapping, or disable it in the crop toolbar.
- **Four corner radii:** edit each corner independently, or link them proportionally. Increasing 8 px to 16 px doubles linked 16 px corners to 32 px. Starting from zero uses an additive change.
- **One timeline:** click or drag the lower track or ruler to seek. Removed the duplicate scrub slider. Trimming and reaching the end no longer unexpectedly jump back to the start. Arrow keys step through frames.
- **Continuous monitor dragging:** the single picker retains pointer capture when moving to another display, so you can continue dragging without releasing the mouse.

Your crop snapping and corner preferences are saved between sessions.

## Downloads

Windows: use the `.exe` installer or portable `.zip`. macOS: choose `arm64` for Apple Silicon or `x64` for Intel, in `.dmg` or `.zip` format.

Builds are unsigned. On Windows, SmartScreen may require More info → Run anyway. On macOS, use System Settings → Privacy & Security → Open Anyway if prompted, and allow Screen Recording for capture.

Installers are published after native build and packaged-app tests pass on all three platforms. SHA256SUMS.txt contains download checksums.
