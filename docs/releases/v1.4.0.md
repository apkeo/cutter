# Cutter 1.4

Precise playback navigation and a studio that stays within reach.

- **Seek on every timeline lane.** Click or drag the video, cursor movement, or mouse click bar, including empty space. Playback follows the exact position instead of snapping to a cursor sample or jumping to the beginning of a held click. Clicking an event still opens its editor.
- **Quick Capture in your tray.** Minimize Cutter to the Windows system tray or macOS menu bar. Its custom menu offers Capture a region, Open studio, Copy latest file, Open captures folder, and Quit Cutter.
- **Minimize to tray** is enabled by default and saved in Settings. Turn it off to use normal window minimization. Closing the window still quits Cutter.
- **A real fullscreen preview.** The button beside the zoom percentage expands the workspace without changing project dimensions. Press Esc or click the button again to return.
- Latest captured/exported files remain available to the tray clipboard action after restarting Cutter.

## Downloads

Windows x64: installer `.exe` or portable `.zip`. macOS 13+: Apple Silicon `arm64` or Intel `x64`, in `.dmg` and `.zip`.

Builds are unsigned. macOS capture requires Screen Recording and Input Monitoring permission. Existing projects and cursor sidecars remain compatible.

Published after all three native platform builds and packaged-app tests pass, including decoded-frame seeking, fullscreen, tray actions, precision crop, cursor editing and media export. Checksums are in SHA256SUMS.txt.
